# Short-form production

- Use the registered Atnos production pipeline and the selected channel profile. Do not create a parallel renderer or repair the final MP4 by hand.
- Keep script, storyboard, assets, narration, subtitles, render, mux and QA tied to the same order and version.
- Every visual action must explain or reinforce the spoken idea. If the renderer cannot express the planned action, report the gap instead of pretending it was rendered.
- Report QC evidence separately from human approval of visual and audio quality.
- Keep delivery local unless the request and the channel's explicit publication gate authorize an external action.
