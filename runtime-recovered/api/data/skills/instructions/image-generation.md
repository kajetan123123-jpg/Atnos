# Atnos skill: image generation

Before creating an image, inspect the active image-generation capability and its current readiness, configured workflow, storage root, and approval or budget requirements. Choose the existing Atnos image lane that matches the brief; do not invent a provider or silently fall back to a different one.

Keep prompts tied to the scene's meaning and channel style. Record the actual workflow and asset provenance through the production path. If no image tool is ready, explain the blocker and prepare a brief only. A selected skill is not proof that an image was generated, accepted, or attached to a production.
