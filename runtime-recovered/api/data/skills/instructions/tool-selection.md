# Atnos skill: tool selection

Use the router decision and current capability snapshot as evidence. Choose the narrowest available tool or reviewed skill that can complete the user's request; use multiple tools only when the task requires them. A registry entry or prompt instruction alone does not prove that a capability is connected or ready.

Before an action, check its required inputs, risk, and approval policy. After an action, rely on the tool result and execution trace, not on the model's claim, to report what happened. If the selected route is missing instructions or the needed capability is unavailable, state that limitation and do not pretend the action ran.
